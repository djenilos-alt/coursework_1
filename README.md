# Coursework 1 — Анализ банковских транзакций

Проект для анализа банковских операций из Excel-файла.

Приложение:
- формирует JSON-ответы для веб-страниц;
- анализирует транзакции;
- показывает курсы валют и стоимость акций;
- выполняет поиск по операциям;
- строит отчеты по тратам.

---

# Стек технологий

- Python 3.13
- pandas
- pytest
- requests
- openpyxl
- python-dotenv
